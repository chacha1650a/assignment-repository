## 확인 1 — 패스키 없이 비공개 자료를 직접 요청하면

화면에서 감추는 것이 아니라 서버가 거절해야 합니다. 로그인 이전에는 응답 본문에 비공개 내용이 한 글자도 없어야 합니다.

<details open><summary><b>[1] GET /api/private/items → 401</b> — 토큰 없이 그냥 요청</summary>

```http
GET /api/private/items
```

**응답 401 Unauthorized**

```json
{
  "error": "unauthorized",
  "message": "패스키로 들어와야 볼 수 있어요."
}
```

</details>

<details open><summary><b>[2] GET /api/private/items → 401</b> — 아무 값이나 토큰이라고 적어 보냄</summary>
