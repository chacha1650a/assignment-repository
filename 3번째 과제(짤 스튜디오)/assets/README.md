크롭해 만들었습니다. 투명 PNG는 JPEG로 만들 수 없어 코드로 생성했습니다
(생성 스크립트의 동작은 아래 "투명 PNG 구성" 참고).

## 투명 PNG 구성

`투명배경_검사용.png`는 알파 값이 서로 다른 세 영역을 일부러 섞어 두었습니다.

- **완전 투명 58.8%** — 배경. 흰색이나 검은색으로 채워지면 결함.
- **반투명 8.0%** — 좌상단 파란 사각형(알파 128). 알파가 뭉개지는지 확인.
- **완전 불투명 33.2%** — 가운데 원, 우하단 삼각형. 모서리에 둬서 잘림도 함께 확인.

검증 결과: 업로드 → 메타데이터 제거 사본 → 최종 저장 파일까지 투명도가 보존되는 것을 확인했습니다
(저장 파일 기준 투명 58.3% / 반투명 9.0% / 불투명 32.8%).

## 사용 권한과 위치 정보

- 원본 이미지는 **무료 라이선스 사이트**에서 받은 것입니다.
- **위치 정보(EXIF)는 앱이 자동으로 제거합니다.** 업로드하면 캔버스에 다시 그린 사본을 쓰기 때문에
  원본의 GPS·촬영기기 정보가 결과물에 남지 않습니다.

## 거부 테스트용

잘못된 파일 거부를 화면으로 보여줄 때 씁니다. PDF나 GIF 등 지원하지 않는 형식이면 아무 파일이나
괜찮습니다. (형식·빈 파일·용량 초과·손상 파일 4가지 거부 경로는 코드 검사로 확인 완료)
