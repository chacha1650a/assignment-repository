# AI와 나의 판단 3줄

1줄(AI에게 맡긴 일): 이미지·문구 합성 캔버스 렌더링, 템플릿 생성·수정·삭제와 새로고침 유지, JSON 가져오기·내보내기와 잘못된 파일 거부 같은 실제 구현을 맡겼고, 극단 입력 12건·세 화면비 일치·템플릿 영속성·JSON 왕복 검사를 자동 스크립트로 돌려서 결함을 찾아내고 고치는 일까지 이어서 맡겼습니다.
2줄(내가 직접 판단한 일): 글래스모피즘은 전체가 아니라 이미지 첨부 영역에만 넣고 인스타그램 톤을 살짝 참고하라는 디자인 방향, 테스트 이미지는 무료 라이선스 사이트에서 받은 사진을 쓰고 부족한 세로·가로형은 그 사진을 잘라서 만들라는 결정, 그리고 select·range 슬라이더에 스타일이 안 먹고 카드가 튀어나온 것을 화면으로 직접 보고 지적해 다시 고치게 한 것은 제가 판단했습니다.
3줄(AI 제안을 따르지 않은 일, 없으면 이유): 없음 — 디자인이나 이미지 출처처럼 방향이 갈리는 지점마다 AI가 먼저 선택지를 묻게 했고 제가 그중 하나를 고른 뒤에만 진행시켰기 때문에, 되돌릴 만큼 독단적으로 진행된 AI 제안 자체가 없었습니다.
