# 짧은 확인 방법

1. **위치**: `https://chacha1650a.github.io/assignment-repository/` 접속 후 「03 짤·카드 스튜디오」 카드 클릭.
2. **3단계 이내 행동**: 이미지 파일(PNG/JPEG) 선택 → 문구 입력 → 비율 버튼(1:1/4:5/9:16) 아무거나 클릭.
3. **통과 모습**: 값을 바꿀 때마다 가운데 미리보기가 즉시 바뀌고, 「이미지 내려받기」를 누르면 미리보기와 똑같은 PNG가 저장된다.
4. **안 될 때 모습**: PNG·JPEG가 아닌 파일을 넣으면 빨간 안내 문구가 뜨고 흔들리며 거부되고, 기존에 하던 작업은 그대로 남는다.
