# 검증 안내서 — 짤·카드 스튜디오

## 어디로 가나요

**https://chacha1650a.github.io/assignment-repository/**

들어가서 **「03 짤·카드 스튜디오」** 카드를 누르면 바로 실행됩니다.

## 무엇을 하나요 (3단계)

1. 왼쪽 **「PNG · JPEG 이미지 선택」** 영역을 눌러(또는 파일을 끌어다 놓아) 사진을 하나 올립니다.
2. **「+ 문구 추가」**를 눌러 문구를 넣고, 내용·위치·색상을 원하는 대로 바꿉니다.
3. 위쪽 **1:1 / 4:5 / 9:16** 비율 중 하나를 고르고, **「이미지 내려받기」**를 누릅니다.

## 무엇이 보이면 통과인가요

- 이미지를 올리면 가운데 캔버스에 **즉시 채워집니다** (별도 "적용" 버튼 없이 바로 반영).
- 문구를 추가·수정할 때마다 캔버스가 **실시간으로 다시 그려집니다.**
- 비율 버튼을 누르면 캔버스 모양이 **정사각형 ↔ 세로형으로 즉시 바뀝니다.**
- 「이미지 내려받기」로 저장한 PNG를 열어 보면 **화면에 보이던 것과 완전히 같은 배치**입니다
  (선택 중이던 문구의 점선 테두리만 제외).
- **템플릿 이름**을 입력하고 **「저장」**을 누르면 오른쪽 목록에 원형 썸네일이 생기고,
  새로고침해도 그대로 남아 있습니다.

> 이미지·문구·템플릿은 전부 이 브라우저 안(localStorage)에만 저장되고 서버로 전송되지 않습니다.
> 인터넷 연결이 끊겨도 이미 연 페이지에서는 계속 편집·다운로드할 수 있습니다.

## 안 될 때

- **페이지가 안 열림** → 새로고침 1회 (배포 반영이 늦을 수 있습니다).
- **이미지가 안 올라감** → PNG·JPEG 형식, 20MB 이하인지 확인하세요. 다른 형식을 넣으면
  업로드 영역이 빨갛게 흔들리며 이유가 안내되고, **하던 작업은 그대로 남습니다.**
- **문구가 캔버스 밖으로 삐져나온 것처럼 보임** → 왼쪽 문구 카드의 **X / Y 슬라이더**로 위치를,
  **크기 슬라이더**로 글자 크기를 직접 조절할 수 있습니다.
- **저장한 템플릿이 갑자기 안 보임** → 다른 브라우저·다른 기기에서는 보이지 않습니다.
  (localStorage는 이 브라우저 전용) **「JSON 내보내기」**로 파일을 받아 옮기면 다른 곳에서도
  **「JSON 가져오기」**로 복원할 수 있습니다.
- **잘못된 JSON 파일을 가져왔을 때** → 형식이 틀리면 안내 문구만 뜨고 **기존 템플릿은 전혀 바뀌지 않습니다.**
- **이전 기록을 지우고 싶음** → 브라우저의 사이트 데이터 삭제. 저장값이 없어도 빈 화면으로 정상 실행됩니다.
