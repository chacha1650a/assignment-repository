- 판정 항목 4가지

## 발견한 결함과 수정 전·후

### 결함 A — 긴 문구가 캔버스 아래로 잘림

- **발견 케이스**: 1번 (긴 한글 한 줄, 세로 위치 85%)
- **원인**: 세로 시작 위치를 `yPct` 값으로 계산만 하고 캔버스 경계를 검사하지 않았다.
  글자 크기 자동 축소는 전체 높이가 캔버스의 92%를 넘을 때만 동작해서,
  높이는 충분하지만 아래쪽에 치우친 문구는 그대로 삐져나갔다.

| | 문구 영역 아래끝 | 캔버스 높이 | 캔버스 밖으로 나간 양 |
|---|---|---|---|
| **수정 전** | 1089px | 1080px | **9px 잘림** |
| **수정 후** | 1058px | 1080px | 0px |

- **수정 내용**: `drawTexts()`에서 문구 덩어리의 위/아래 끝을 계산해,
  캔버스 밖으로 나가면 안쪽(여백 2%)으로 밀어 넣도록 했다.

```js
const margin = h * 0.02;
const blockTop = startY - fs * 0.75;
const blockH = totalH + fs * 0.3;
if (blockTop + blockH > h - margin) startY -= (blockTop + blockH) - (h - margin);
if (startY - fs * 0.75 < margin) startY += margin - (startY - fs * 0.75);
```

### 결함 B — 문구를 2개 추가하면 완전히 겹침

- **발견 케이스**: 10번 (문구 추가 버튼을 두 번 누른 상황)
- **원인**: 「문구 추가」가 만드는 새 문구의 세로 위치가 항상 `yPct: 85`로 고정되어 있었다.
  두 번 누르면 같은 좌표에 정확히 포개져, 사용자가 직접 옮기기 전까지 글자가 겹쳐 보였다.

| | 문구 3개의 세로 위치 | 최대 겹침률 |
|---|---|---|
| **수정 전** | 85 / 85 / 85 | **100% 겹침** |
| **수정 후** | 85 / 15 / 50 | 0% |

- **수정 내용**: 빈 자리를 찾아 배치하는 `nextTextYPct()`를 추가했다.
  밈의 기본 배치대로 아래(85) → 위(15) → 가운데(50) 순으로 놓고,
  선호 위치가 모두 차면 겹치지 않는 자리를 찾는다.

```js
function nextTextYPct() {
  const preferred = [85, 15, 50, 70, 30, 60, 40];
  const used = state.texts.map((t) => t.yPct);
  const isFree = (y) => used.every((u) => Math.abs(u - y) >= 10);
  const spot = preferred.find(isFree);
  if (spot !== undefined) return spot;
  for (let y = 10; y <= 90; y += 5) if (isFree(y)) return y;
  return clamp(85 - state.texts.length * 4, 5, 95);
}
```

## 결함이 아닌 것 — 반투명 픽셀의 1/255 오차

11번(투명 PNG) 검사에서 미리보기와 저장 파일 사이에 **49픽셀 차이**가 처음 보고되었으나,
원인을 확인한 결과 **앱의 결함이 아니라 브라우저의 동작 한계**였다.

| 픽셀 종류 | 차이 개수 |
|---|---|
| 완전 불투명 (알파 255) | **0** |
| 완전 투명 (알파 0) | **0** |
| 반투명 (알파 24·34·54) | 49 |

- 알파 값 자체는 **전부 일치**했고, RGB만 **최대 1/255** 달랐다.
- 브라우저는 캔버스를 미리 곱한 알파(premultiplied alpha)로 보관한다.
  PNG로 저장했다 다시 읽는 과정에서 알파가 낮은 픽셀은 반올림 오차가 생기며, 앱에서 없앨 수 없다.
- 전체 1,166,400픽셀 중 49픽셀(0.004%)이고 차이가 1/255라 육안으로 구분되지 않는다.

따라서 검사 기준을 **불투명·투명 픽셀은 완전 일치를 요구하고, 반투명 픽셀만 1/255까지 허용**하도록
고쳤다. 이 기준에서 12건 모두 화면과 파일이 일치한다.
