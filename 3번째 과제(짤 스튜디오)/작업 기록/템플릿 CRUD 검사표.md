# 템플릿 생성·불러오기·수정·삭제 검사표

- 검사일: 2026-08-24
- 목적: 체크리스트 "템플릿 생성·불러오기·수정·삭제가 유지됩니다" 확인
- 방법: 실제 새로고침(페이지 리로드)을 두 번 끼워 넣어, localStorage가 아니라
  **화면에 다시 그려지는 데이터**가 맞는지까지 검사

## 1. 생성 (템플릿 3개, 서로 다른 비율)

| 이름 | 비율 | 이미지 | 결과 |
|---|---|---|---|
| 템플릿A-정사각 | 1:1 | 고냥이.jpg | 저장됨, 썸네일 생성됨 |
| 템플릿B-스토리 | 9:16 | 고양이_세로형.jpg | 저장됨, 썸네일 생성됨 |
| 템플릿C-피드 | 4:5 | 고양이_가로형.jpg | 저장됨, 썸네일 생성됨 |

→ **(새로고침)** → localStorage가 아니라 화면 목록에서 3개, 이름 3개, 썸네일 3개 모두 정상 렌더 확인.

| 확인 항목 | 결과 |
|---|---|
| 비율이 1:1로 전환됨 | 통과 |

| 이미지가 로드되어 캔버스에 그려짐 | 통과 |
| 템플릿 이름 입력칸에 이름이 채워짐 | 통과 |

## 3. 수정

불러온 템플릿A의 문구 내용과 크기를 바꾸고 같은 이름으로 다시 저장.

| 확인 항목 | 결과 |
|---|---|

## 6. 예외 처리

| 케이스 | 결과 |
|---|---|
| 이름을 비운 채 저장 시도 | 알림으로 안내, 저장 개수 변화 없음 |
| localStorage 용량 초과 시 저장 (이전 검증 항목) | 실패 시 alert 안내, 기존 템플릿 보존 — [작업일지] 참고 |

## 최종 결과

생성·불러오기·수정·삭제 전 항목 통과. 두 차례의 실제 새로고침 이후에도 데이터가
정확히 유지되어, localStorage 저장뿐 아니라 **화면 복원까지** 정상 동작함을 확인했다.
