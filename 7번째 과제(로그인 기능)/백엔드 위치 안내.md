# 백엔드 코드는 어디에 있나요?

이 과제의 인증 백엔드(Express + SQLite + bcryptjs)는 저장소 루트의 **`mochi-diary-auth-backend/`** 폴더에 있습니다.

- 서버 코드: [`/mochi-diary-auth-backend/server.js`](../mochi-diary-auth-backend/server.js)
- 배포 방법과 API 목록: [`/mochi-diary-auth-backend/README.md`](../mochi-diary-auth-backend/README.md)
- 5일 기록을 배포 서버에 넣는 스크립트: [`/mochi-diary-auth-backend/seed-5days.js`](../mochi-diary-auth-backend/seed-5days.js)
- 화면(이 폴더): `index.html`, `app.js`, `style.css`, `character.html`

## 왜 과제 폴더 안에 없나요

Render 같은 호스팅 서비스는 배포 설정(Root Directory, Build Command)에 넣을 수 있는 문자를
`^[A-Za-z0-9-_./]*$` 로 제한해서, `7번째 과제(로그인 기능)/backend` 처럼 한글·괄호가 들어간 경로를 받지 못합니다.
그래서 배포가 가능하도록 영문 이름의 폴더로 따로 두었습니다. 6번 과제 때와 같은 이유입니다.

## 6번 과제 백엔드는 어떻게 됐나요

`mochi-diary-backend/` (6번 과제용, 로그인 없이 공용 API 키로 쓰는 서버)는 **한 줄도 고치지 않았습니다.**
6번 제출물이 지금도 그대로 열려야 하기 때문입니다.
7번은 `mochi-diary-auth-backend/` 라는 **별도 서비스**로 새로 배포합니다.

## 로그인 없이는 동작하지 않습니다

6번 화면은 서버에 연결하지 않으면 브라우저 localStorage에 저장하는 "로컬 모드"로 돌아갔지만,
**7번 화면에는 로컬 모드가 없습니다.** 로그인해야만 기록을 읽고 쓸 수 있고, 모든 저장은 서버를 거칩니다.
"내 자료를 나만 본다"를 브라우저가 아니라 서버가 책임져야 하기 때문입니다.
