# AI 사용 기록 3줄

1줄: 네트워크 보안 기초를 배우는 폭탄 해체 웹 게임을 HTML·CSS·JS 세 파일로 만들어 달라고 요청했고, 매판 문제가 바뀌는 출제 방식과 조작 방식 추가, 저장·일시정지·효과 끄기 기능까지 이어서 요청했습니다.
2줄: 폭탄과 펼친 책을 CSS로 그린 코드, 문제 11종과 조작 5종을 만드는 생성기 코드, 그리고 20회 플레이 기록과 저장값 손상 9종 검사처럼 손으로 하기 번거로운 반복 검사 결과를 활용했습니다.
3줄: 게임 이름과 오조작 시 정답 대신 조항 힌트만 주는 규칙은 제가 정했고, AI가 데이터도 없이 회복 시간을 4초로 바꾸고 "기록을 보고 낮췄다"는 주석까지 달아 둔 것을 되돌려 실제 20회를 돌린 뒤 4초로 확정했으며, 브리핑 화면이 아직 5초라고 안내하던 것도 직접 찾아 고쳤습니다.
