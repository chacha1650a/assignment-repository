## 촬영 방법
Chrome 헤드리스(`--headless=new --window-size=1440,900`)로 실제 페이지를 열어 촬영했습니다.
게임 상태(진행 중 / 짝 맞추기 / 결과)를 찍기 위해 촬영본에 한해 시작 상태를 지정하는 스크립트를 덧붙였고,
**게임 코드 자체는 수정하지 않았습니다.** 촬영본은 저장소에 포함하지 않습니다.
