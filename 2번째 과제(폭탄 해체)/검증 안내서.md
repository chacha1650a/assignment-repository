# 검증 안내서 — 차단선 (네트워크 보안 폭탄 해체)

## 어디로 가나요
https://chacha1650a.github.io/assignment-repository/

## 무엇을 하나요 (3단계 이내)
1. 위 주소 접속 → **「02 차단선」** 카드 클릭
2. 브리핑 화면에서 규칙을 읽고 **「해체 시작」** 클릭 → 카운트다운이 30.0초부터 줄기 시작
3. 화면 오른쪽 **현장 매뉴얼**에서 지시된 조항(§1~§9)을 찾아 대조하고 답을 고름 — 다섯 회로를 모두 끊으면 완료

## 무엇이 보이면 통과인가요
- 2번 클릭 후 회로 1이 열리고 **카운트다운이 실시간으로 줄어든다**
- 회로가 바뀔 때마다 **매뉴얼이 해당 조항으로 스스로 펼쳐지고** 그 페이지에 책갈피 끈이 내려온다
- 정답 시 초록 표시와 함께 **+5.0s**가 뜨고 다음 회로로 넘어간다 (단 30초를 넘지 않는다)
- 오답 시 오조작 램프가 하나 켜지고 **정답 대신 매뉴얼 조항 힌트**가 나온다
- 다섯 회로를 모두 끊으면 **「해제 완료」** 작전 기록 화면이 나타난다

## 함께 확인해 볼 것
- 매뉴얼 아래 **§1~§9 탭**을 눌러 책장이 실제로 넘어가는지 (좌우 화살표 키로도 됨)
- 새로고침 후 다시 시작하면 **문제 구성이 매번 달라지는지** (11종 중 5종 무작위)
- 브라우저 창을 좁혀도 **가로 스크롤이 생기지 않는지** (760px 미만에서 매뉴얼이 낱장 모드로 전환)

## 안 될 때
- 페이지가 안 열림 → 새로고침 1회 (일시적 배포 지연일 수 있음)
- 카운트다운이 멈춰 보임 → 브라우저 탭이 백그라운드에 있으면 시간이 흐르지 않을 수 있으니, 탭을 앞에 둔 상태로 다시 시작
- 특정 회로가 안 풀림 → 오조작 힌트가 가리키는 **매뉴얼 조항 번호**를 탭에서 직접 눌러 확인
