### 확정 사양 반영
- 제한시간 **30초**, 정답 시 **+5초** 회복하되 `Math.min(30, ...)` 로 **상한 30초** 고정
- 오답 **3회** 누적 시 즉시 폭발 / 타이머 0 도달 시 폭발
- 모듈 **5개** 연속 해제 시 성공(DEFUSED)
- 매판 6종 유형에서 **비복원 5개 추출**, 각 유형 내부 값(IP·포트·URL·비밀번호·패킷)도 난수 생성

### 구현한 모듈 6종
1. `wire` — 배선 절단 (사설/공인/루프백 IP 판별) · SVG 케이블 4가닥
2. `port` — 포트 키패드 (서비스 ↔ 표준 포트)
3. `phish` — URL 검증 (정상/피싱 선택, 지시문 랜덤 반전)
4. `protocol` — 프로토콜 스위치 (암호화/평문)
5. `auth` — 인증 다이얼 (비밀번호 강도)
6. `firewall` — 방화벽 정책 ALLOW/DENY (스푸핑 시나리오 포함)

### 디자인 결정
- 단색 배제 — 4중 radial-gradient 배경 + 그리드 라인 + SVG feTurbulence 노이즈 레이어
- 이모지 배제 — 모든 아이콘을 인라인 SVG 로 작성 (방패, X, 자물쇠, 케이블, 문서)
- 서체: IBM Plex Mono(수치) + IBM Plex Sans KR(본문)
- 타이머: SVG 링 게이지 `stroke-dashoffset` + 10초 이하 진입 시 붉은 비네트 펄스
- 매뉴얼: 현재 모듈에 해당하는 §만 활성 강조 + 자동 스크롤, 나머지는 흐리게

### 검증 기록
- **문제 은행 4000판 시뮬레이션** (node) — 정답 인덱스 범위 이탈 0건, 보기 중복 0건, 유형 중복 0건, 6종 출현 균등(약 3300회씩)
- **정상 클리어 경로** — 5모듈 전부 정답 → `DEFUSED`, 잔여 29.2초 (보너스 상한 정상 동작 확인)
- **실패 경로** — 오답 3회 → `DETONATED` + 폭발 플래시 정상
- 브라우저 콘솔 에러 0건

### 수정한 버그
1. `makePhishModule` 에서 정답 객체와 보기 배열의 객체 참조가 달라 `indexOf` 가 -1 을 반환하던 문제 → 동일 참조 사용으로 수정
2. `.manual` 에 `position: relative` 누락 → `offsetTop` 이 sticky 조상 기준으로 계산되어 자동 스크롤 위치가 어긋나던 문제 수정
3. 오답 피드백이 정답을 그대로 노출해 남은 재시도가 무의미해지던 문제 → 기회가 남아 있을 때는 유형별 **힌트만** 출력하고, 정답 해설은 정답 시 또는 3번째 오답(게임 종료) 시에만 노출

## 2026-08-18 · 2차 — 폭탄 CSS 드로잉 + 매뉴얼 책 전환

### 요청
1. 폭탄을 CSS로 그릴 것
2. 매뉴얼을 책 형태로 펼쳐서 볼 수 있게 할 것

### 작업
- **폭탄 케이싱을 순수 CSS로 구현** — 이미지·SVG 없이 그래디언트만 사용.
  금속 몸체(리벳 4개 + 헤어라인 결 + 상단 하이라이트), 노랑/검정 위험 테이프,
  스텐실 각인, 파인 모듈 베이, C-4 스틱 3개, 배터리 팩, 상태 LED 3개, 방열 슬릿.
  LED 는 잔여 10초 이하에서 깜빡임 주기가 0.45초로 빨라진다.
- **매뉴얼을 좌우 2페이지 펼침 책으로 교체** — 스크롤 패널 폐기.
  `perspective` + `rotateY` + `backface-visibility` 로 낱장이 실제로 넘어간다.
  크림색 종이 질감, 인쇄물 잉크 색상, 제본선, 페이지 번호, 붉은 "현재 모듈" 스탬프.
  §1~§6 탭 / 화살표 버튼 / 키보드 ←→ 로 이동. 모듈이 바뀌면 해당 절이 실린 면으로 자동으로 넘어간다.
- 매뉴얼 원문을 `<template>` 으로 옮기고 JS 가 페이지에 분배하도록 구조 변경.
- 페이지 폭에 맞춰 §1 표기를 CIDR(`10.0.0.0/8`)로 축약, 각 절에 한 줄 요약(`man__lead`) 추가.

### 검증 기록
- 5모듈 정주행 — 매 모듈마다 책이 정확한 펼침면으로 넘어가고(`1–2`, `3–4`, `5–6`),
  해당 페이지에 "현재 모듈" 스탬프가 찍히는 것을 5/5 확인 → `DEFUSED`
- 낱장 넘김 중간 각도(-52°)에서 3D 렌더링 정상 확인 (원근 + 뒷면 은폐)
- 375×812 모바일 — `is-single` 모드 전환, 왼쪽 페이지 숨김, 페이지 번호 `2 / 6` 정상
- 브라우저 콘솔 에러 0건

### 수정한 버그
- 좁은 화면에서 `.readout` 의 배지 텍스트가 세로 한 글자씩 쪼개지던 문제 →
  `flex-wrap` + `white-space: nowrap` 적용, 560px 이하에서는 세로 배치로 전환

### 참고
- 하네스 문서의 "CSS로 캐릭터를 그리지 말 것" 조항은 **캐릭터**에 대한 제약으로 보고,
  장치(폭탄 케이싱)는 CSS 드로잉으로 진행했다.

   `lampFlicker`(불규칙 명멸) · `lampSway`(좌우 흔들림)
3. `.room-dust` — 빛줄기 속 부유 먼지, 두 겹이 서로 다른 속도로 표류
4. `.room-vignette` — 모서리를 깊게 눌러 갇힌 느낌

### 함께 맞춘 것

- 종이는 크림색 → **등불이 비스듬히 떨어지는 낡은 지질**, 잉크도 먹빛/적갈로

- `panel__dot--cyan` → `panel__dot--lamp` 로 클래스명 정리

### 수정한 버그
- 책의 1단/2단 레이아웃 전환이 `resize` 이벤트에만 의존해, 이벤트가 유실되면
  화면 폭과 모드가 어긋난 채 남던 문제.
  → `syncLayout()` 을 분리해 `goto()` · `openTo()` 진입 시마다 폭을 직접 확인하도록 변경.
  이벤트(`resize`, `matchMedia change`)는 보조 수단으로만 유지.
  1560px ↔ 375px 양방향 전환을 이벤트 없이 자기 교정하는 것 확인.

### 검증 기록
