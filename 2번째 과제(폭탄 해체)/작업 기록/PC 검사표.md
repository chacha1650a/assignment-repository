> 고정 배경인 빛 원뿔(`.room-lamp`)은 화면보다 넓게 그려지지만 `pointer-events: none` 이고
> `body { overflow-x: hidden }` 으로 잘려서 가로 스크롤을 만들지 않는다. 위 표의 문서 스크롤 폭이 그 근거다.

## 2. 연속 입력 — 중복 판정 없음

| 검사 | 결과 |
|---|---|
| 정답 자리를 20번 연타 | 판정 **1회**만 기록됨 (회로가 한 번만 넘어감) |
| 오답 자리를 20번 연타 | 오조작 **1회**만 누적 |
| 숫자키를 누른 채 유지 (repeat 15회) | 오조작 **0회** — 반복 입력은 무시됨 |

판정 직후 잠금이 걸리고 다음 회로가 열릴 때 풀린다. 키 반복은 `e.repeat` 으로 걸러낸다.

## 4. 큰 시간 공백 처리

한 프레임에 8초짜리 공백이 들어와도 **0.25초만** 깎인다. (상한 `CONFIG.MAX_DT`)

| 입력 | 깎인 시간 |
|---|---|
| 정상 프레임 (16ms) | 0.016초 |
| 8초 공백 | **0.250초** (상한에서 잘림) |
| 음수 시간(시계 역행) | 0.000초 |

이 처리가 없으면 다른 탭에 다녀온 직후 곧바로 시간 초과로 죽는다.

## 5. 10분 연속 실행

| 검사 | 값 |
|---|---|
| 헤드리스 연속 실행 (20판) | 게임 시계 기준 **776초 = 12.9분** |
| 그 동안 콘솔 오류 | **0건** |
| 실제 시각 기준 연속 실행 | **16.4분** (소크 검사) |
| 소크 검사 중 진행한 판 | **414판** |
| 소크 검사 중 콘솔 오류 | **0건** |

소크 검사는 1초마다 시계를 밀고, 회로를 풀고, 책장을 넘기고, 소리·움직임 토글을 반복해서 누르는
동작을 10분 넘게 이어간 것이다. `window.onerror` · `unhandledrejection` · `console.error` 를 모두 수집했다.
