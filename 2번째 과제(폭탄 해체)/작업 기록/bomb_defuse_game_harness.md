# [Optimized Harness] 네트워크 보안 폭탄 해체 게임 (Claude Opus 전용)

## 0. 시스템 제어 지침 (System Directive)
* **목표**: 30초 제한 시간, 3회 오답 제한의 네트워크 보안 지식 기반 폭탄 해체 웹 게임 구현.
* **토큰 최적화 규칙**: 부가적인 설명, 주석, 긴 서론/결론을 일체 배제하고 오직 **코드 블록과 핵심 로직**만 간결하게 출력할 것.

## 1. 프로젝트 아키텍처 (File Structure)
작업 결과물은 반드시 아래 3개의 독립된 파일 코드로 분리하여 제공할 것.
1. `index.html`: DOM 구조 및 뷰 레이아웃
2. `style.css`: 긴박감 있는 UI (붉은색 경고등, 타이머 애니메이션)
3. `script.js`: 타이머(30초), 오답 카운트(최대 3회), 메뉴얼 데이터 및 정오답 판정 로직

## 2. 핵심 게임 메커니즘 규칙
* **제한 시간**: 30초 카운트다운 시작 시 동작, 0초 도달 시 폭발(FAIL).
* **목숨(오답 제한)**: 틀릴 때마다 카운트 증가, 3회 도달 시 폭발(FAIL).
* **성공 조건**: 모든 기초 네트워크 보안 문제/절차를 시간 내 올바르게 해결 시 성공(SUCCESS).

## 3. 출력 포맷 규격
* 설명 생략 및 즉시 코드 작성 시작.
* 파일별 마크다운 코드 블록(` ```html `, ` ```css `, ` ```javascript `)으로만 응답 구성.

## 4. 아이디어 의논
* 큰 아이디어 및 어려운 작업은 내게 물어볼 것
* CSS로 캐릭터를 절대 그리지 않을 것.
* 무료 저작권 캐릭터 & 이미지 적극 활용
