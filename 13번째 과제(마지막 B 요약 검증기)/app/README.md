# 요약 검증기

AI에게 문서 요약을 맡기는 사람이 결과를 받았을 때, 요약 문장을 원문과 하나씩 대조해 **지어낸 값**과 **과잉 방어**(원문에 있는 정보를 "문서에 없음"이라고 쓴 것)를 표시해 주는 앱입니다.
김대훈의 10번 논문 「지시문의 모호성은 요약 과제의 할루시네이션을 늘리는가」의 결과를 바탕으로 만들었습니다.

## 실행 방법

설치할 것이 없습니다. 서버, 로그인, API 키, 환경 변수가 필요 없습니다.

1. 이 폴더(`index.html`, `style.css`, `app.js`, `samples.js`)를 아무 곳에 풉니다.
2. `index.html`을 더블클릭해 브라우저(Chrome·Edge 등)로 엽니다.
3. 위쪽 **예시로 바로 실행**을 누르거나, 왼쪽 프로젝트 창의 예시 파일(A·B·C)을 누릅니다. 직접 쓸 때는 `원문.md`·`요약.md` 칸에 붙여 넣고 **▶ 검사하기**(Ctrl+Enter)를 누릅니다.
4. 아래 실행 창에 검증 과정이 한 줄씩 나온 뒤, 에디터가 검토 화면으로 바뀝니다. 요약 줄에 마우스를 올리면 근거 원문 줄과 띠로 이어집니다. **편집**을 누르면 다시 고칠 수 있습니다.

화면은 IntelliJ 같은 코드 편집기 모양입니다. 밝은/어두운 화면은 오른쪽 위 버튼으로 바꿉니다. 인터넷이 없으면 글꼴(JetBrains Mono)만 기본 글꼴로 바뀌고 나머지는 그대로 동작합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 (툴바 · 프로젝트 창 · 에디터 두 칸 · 실행/문제 창 · 검증 결과 창) |
| `icon.svg` | 앱 아이콘 |
| `og.png` | 링크를 붙였을 때 뜨는 미리보기 이미지 |
| `style.css` | 모양 (밝은/어두운 화면 모두 지원) |
| `app.js` | 대조 규칙. 숫자·날짜·파일명·영문 낱말·직함 붙은 이름을 원문과 비교하고, "문서에 없음" 표시는 원문의 관련 문장을 다시 찾습니다 |
| `samples.js` | 예시 데이터. 10번 논문 실험에 쓴 **가상** 프로젝트 로그와 응답입니다. 등장하는 인물·회사는 실험용으로 지어낸 것이며 실제 개인정보는 없습니다 |

## 판정 종류

| 판정 | 뜻 |
|---|---|
| 근거 있음 | 문장 속 값이 모두 원문에 있거나, 원문에 같은 내용의 문장이 있음 |
| 원문에 없는 값 | 원문에서 찾지 못한 숫자·날짜·파일명 등이 있음 (지어냈거나 잘못 옮겼을 가능성) |
| 과잉 방어 의심 | 요약은 "문서에 없음"이라 했지만 원문에 관련 문장이 있음 |
| '없음' 표시 적절 | "문서에 없음"이라 했고 원문에서도 찾지 못함 |
| 직접 확인 | 자동으로 대조할 값이 없어 사람이 확인해야 함 |

## 개인정보와 비밀값

- 입력한 글은 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.
- 소스에 API 키·토큰·비밀번호가 없습니다. 외부 서비스를 부르지 않으므로 환경 변수도 쓰지 않습니다.
