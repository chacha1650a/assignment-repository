# AI 사용 기록 3줄

1줄: 관심 분야(LLM 활용·프롬프트)를 던지고 확인 가능한 질문 10개를 뽑아 달라고 요청했고, 그중 데이터를 직접 모을 수 있는 것을 추려 "지시문 모호성 → 할루시네이션"이라는 최종 가설로 좁혀 나갔습니다.
2줄: AI가 실험용 가상 소스 문서와 정답표, 두 가지 지시문 버전을 만들고, 서브에이전트로 모호·구체 조건 각 10회씩 총 20회를 독립된 맥락에서 반복 실행해 응답을 모았으며, 선행 연구 후보를 검색해 초록을 요약해 주는 데 활용했습니다.
3줄: 실행 방식은 API 자동화 대신 서브에이전트 방식으로 바꾸라고 직접 지시했고(발급 과정에서 키가 화면에 노출되는 사고가 있어 바로 폐기·전환함), AI가 1차로 채점한 결과 중 `specific_03`이 실제로는 문서에 있는 정보를 "없음"으로 잘못 표시한 오류라는 것과 선행 연구 5건이 실제로 존재하는지를 직접 대조해 확인했으며, "가설이 데이터를 뒷받침하지 않는다"는 최종 판단은 AI 초안을 검토한 뒤 제가 확정했습니다.
