# 응답 저장 방법 (수동 반복 방식)

API 대신 Claude.ai 웹/앱에서 직접 반복해서 모은다. 아래 순서를 정확히 지킬 것 — 그래야 24번의 시행이 서로 독립적이라고 말할 수 있다.

## 절차

1. Claude.ai에서 **새 대화(New Chat)**를 연다. (이전 대화에 이어서 보내면 안 됨 — AI가 문맥을 기억해서 조건이 오염된다.)
2. `../복사용_프롬프트_모호.txt` 파일을 열어 전체 내용을 복사해 그대로 붙여넣고 전송한다.
3. 받은 응답 전체를 복사해 이 폴더에 `vague_01.txt`로 저장한다.
4. 그 대화는 닫고, 다시 새 대화를 열어 2~3번을 반복한다. `vague_02.txt` ~ `vague_12.txt`까지 총 12개.
5. 같은 방식으로 `../복사용_프롬프트_구체.txt`를 새 대화마다 붙여넣어 `specific_01.txt` ~ `specific_12.txt` 12개를 모은다.

## 완료 후 체크리스트

- [ ] vague_01.txt ~ vague_12.txt (12개)
- [ ] specific_01.txt ~ specific_12.txt (12개)
- [ ] 각 파일에 응답 텍스트만 저장했는지 확인 (프롬프트는 다시 안 적어도 됨)
- [ ] `../채점표.csv`에 파일별로 `../사실목록(정답표).md` 기준 할루시네이션 개수 기록

## 참고

애초 계획은 `scripts/run_experiment.py`로 Anthropic API를 자동 호출하는 것이었으나, API 키 발급·크레딧 결제·키 보안 관리 부담이 이번 소규모 실험(24회) 대비 과하다고 판단해 Claude.ai 수동 반복 방식으로 바꿨다. 스크립트는 참고용으로 남겨 둔다.
