# 두 번 실행한 결과 비교

같은 `input/` 폴더로 서로 다른 출력 폴더(`output_run1/`, `output_run2/`)에 각각 실행한 뒤 `diff -r`로 비교했습니다.

```
$ node generate.js ./input ./output_run1
$ node generate.js ./input ./output_run2
$ diff -r ./output_run1 ./output_run2
(출력 없음 — 차이 없음, exit code 0)
```

추가로 `generate.js`와 `input/`만 새 임시 폴더(`%TEMP%/device_fresh_test`)에 복사해 그 안에서 실행한 결과도 원본 `output/`과 `diff -r`로 비교해 차이가 없음을 확인했습니다. 이 폴더의 `numbers.json`·`candidates.md`는 그 실행 결과 그대로입니다.
