## 0단계 — 서버 연결 (최초 1회만)

이 다이어리는 Node/Express + SQLite로 만든 실제 백엔드에 연결해 저장할 수 있어요 (연결하지 않으면 브라우저 localStorage에만 저장되는 로컬 모드로 동작합니다).

1. 상단의 **🔌 서버 연결** 버튼을 누릅니다.
2. 아래 입력창에 다음을 각각 입력합니다.
   - 백엔드 주소: `https://mochi-diary-backend.onrender.com`
   - API 키(검증용): `ghJ9_ILENzlvuti9tngZtPrq`
3. **연결** 버튼을 누르면 "연결됨 — 서버에 저장돼요" 문구가 뜹니다.

> 이 키는 검증 전용으로 별도 발급한 값이라 실제 사용 키와는 다릅니다. 한 번 연결하면 브라우저에 저장되어 다음부터 다시 입력할 필요가 없어요.
> 무료 서버라 15분 이상 요청이 없으면 잠들어요 — 연결 시 첫 응답이 몇십 초 걸릴 수 있습니다(정상입니다).

## 무엇을 하나요 (3단계)

1. 달력에서 아무 날짜나 누르고, 기분 이모지 하나를 고른 뒤 텍스트를 적고 **저장**을 누릅니다.
2. 텍스트창 아래 **오늘의 습관 기록**에 항목·값·단위(예: 운동 / 30 / 분)를 넣고 **추가**를 누릅니다.
3. 상단 **내보내기**로 백업 파일을 받고, **가져오기**로 그 파일을 다시 선택해 복원되는지 확인합니다.

## 무엇이 보이면 통과인가요

- 저장한 날짜에 달력 점이 찍히고, 새로고침해도 기분·텍스트·습관 기록이 그대로 남아 있습니다.
- 습관 기록을 추가·삭제하면 목록과 함께 아래 **이번 주 요약**(월~일 기준 항목별 합계)이 같이 바뀝니다.
- 상단 배지에 **"데이터 형식 v2"**가 보이고, 예전 형식 기록이 있었다면 자동 변환 안내 문구가 함께 뜹니다.
- 내보낸 JSON을 다시 가져오면 같은 날짜·기분·텍스트·습관이 그대로 복원됩니다.
- **전체 삭제**를 누르면 모든 기록이 0건이 되고, JSON이 아닌 파일을 가져오면 기존 기록은 그대로 남은 채 빨간 오류 문구만 뜹니다.
- 습관 기록에서 항목이나 값이 비어 있으면 "추가"가 되지 않고 오류 문구가 뜹니다.

> 서버에 연결한 상태라면 위 기록은 실제 백엔드(Render + SQLite)에 저장됩니다. 검증용 키로 접속하면 다른 검증자와 같은 데이터베이스를 공유하니, 실제 개인 일기 대신 위 3단계처럼 가상 기록으로 검증해주세요.

## 안 될 때

- **페이지가 안 열림** → 새로고침 1회 (배포 반영이 늦을 수 있습니다).
- **모찌 캐릭터 칸이 빈 화면으로 보임** → 새로고침 1회. 그래도 안 되면 브라우저의 iframe 차단 설정을 확인하세요.
- **습관 "추가"가 안 눌림** → 항목과 값을 모두 채웠는지 확인하세요 (값은 숫자만 가능).
- **가져오기 후 이전 기록이 사라짐** → 가져오기는 기존 기록을 통째로 덮어씁니다 (의도된 동작). 되돌리려면 미리 받아둔 백업 파일을 다시 가져오세요.
- **옛날 스타일이 보임** → 강력 새로고침(Ctrl+Shift+R).
- **서버 연결이 "API 키가 올바르지 않아요" 오류를 냄** → 주소·키에 공백 없이 정확히 입력했는지 확인하세요. 계속 안 되면 **로컬 모드로**를 눌러 로컬 모드로도 CRUD 검증이 가능합니다.
- **연결 직후 로딩이 오래 걸림** → 무료 서버가 잠들어 있었던 것으로, 첫 요청만 몇십 초 걸립니다. 잠시 기다리면 정상 응답합니다.
