# AI와 나의 판단 3줄

1줄(AI에게 맡긴 일): 모찌 캐릭터 위젯 경량화(눈·볼 쓰다듬기 반응만 남기고 캔버스 물리 애니메이션 유지), 일기 CRUD·달력·D-Day·습관 기록(항목+값+단위)·주간 요약 집계·내보내기/가져오기/전체 삭제·스키마 v1→v2 자동 변환·줄노트 질감 배경까지 전체 코드 작성과, 로컬 브라우저로 직접 클릭해가며 검증하는 작업을 맡겼습니다.
2줄(내가 직접 판단한 일): 원본 모찌 위젯의 간식 주기·꾹꾹이·호감도 게임 요소는 실제 다이어리에는 안 어울린다고 판단해 빼라고 지시했고, 화면 구조(캐릭터/D-Day를 위에, 일기 CRUD를 아래 큰 박스로)는 제가 손그림으로 직접 그려서 그대로 반영시켰습니다.
3줄(AI 제안을 따르지 않은 일): 습관 기록을 별도 섹션 없이 "기분 값(1~5)+단위"로 흡수해 구조를 단순화하자는 AI 제안 대신, 기분/텍스트는 그대로 두고 습관 기록을 완전히 별도 섹션으로 추가하는 쪽을 선택했습니다.
