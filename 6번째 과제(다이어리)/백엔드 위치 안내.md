# 백엔드 코드는 어디에 있나요?

이 과제의 백엔드(Express + SQLite API 서버)는 저장소 루트의 **`mochi-diary-backend/`** 폴더에 있어요.

## 왜 과제 폴더 안에 없나요

Render 같은 호스팅 서비스는 배포 설정(Root Directory, Build Command)에 입력할 수 있는 문자를
`^[A-Za-z0-9-_./]*$` 로 제한해서, `6번째 과제(다이어리)/backend` 처럼 한글·괄호가 들어간 경로를 받지 못해요.
그래서 배포가 가능하도록 영문 이름의 폴더로 옮겼습니다.

- 백엔드 코드 + 배포 방법: [`/mochi-diary-backend/README.md`](../mochi-diary-backend/README.md)
- 프론트엔드(이 폴더): `index.html`, `script.js`, `style.css`, `character.html`

## 백엔드 없이도 동작해요

프론트엔드는 백엔드를 연결하지 않으면 브라우저의 localStorage에만 저장하는 **로컬 모드**로 동작합니다.
상단 **🔌 서버 연결** 패널에 백엔드 주소와 API 키를 입력하면 그때부터 서버에 저장돼요.
