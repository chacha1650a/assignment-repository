# AI B 검증 로그 — 5번째 과제(실습 이어가기)

## 0. 시작 조건

이 검증은 **인계 문서(`작업 기록/인계 문서.md`)만 읽고 시작**했다. 이전 대화 맥락(AI A와
사용자 사이의 원본 세션)은 전달받지 않았고, 인계 문서가 참고하라고 지시한
`../harness.md`(특히 "검사 10개(ID·입력·기대값 고정)" 표)만 추가로 읽었다. 그 외의 배경
지식(왜 습도 기능을 골랐는지, 지도·그래프를 어떤 시행착오로 붙였는지 등의 세부 서사)은
두 문서에 적힌 범위 안에서만 파악했다.

- 실행: `C:\gov\SKT 알레프 A반 과제(김대훈)\5번째 과제(실습 이어가기)`에서
  `python -m http.server 8792` 로컬 정적 서버 실행 → `http://localhost:8792/index.html`을
  브라우저(자동화 브라우저 도구)로 열어 검사 10개를 실제 조작으로 재현.
- 검증 후 서버 프로세스는 종료함.
- **기존 파일은 전혀 수정하지 않았다** — `index.html`/`script.js`/`style.css`/
  `harness.md`/`인계 문서.md` 등은 읽기만 했고, 이 로그 파일만 새로 작성했다.

## 3. T05-C07 재현 상세 (정상값이 아예 없는 최초 상태)

1. 정상 로드 상태에서 `localStorage.clear()` 실행 후 `location.reload()` — 리로드 시
   페이지가 다시 실제 네트워크 조회에 성공해 정상값(`25.3°C`, `90%`)을 새로 받아왔다.
   즉 **리로드만으로는 "정상값이 아예 없는 최초 상태"가 재현되지 않는다** — `LASTGOOD_KEY`가
   즉시 다시 채워지기 때문.
2. 이 정상 상태에서 `localStorage.clear()`를 **한 번 더**(리로드 없이) 실행한 뒤 「개발자
   테스트」의 `오프라인` 버튼을 클릭했다. `getLastGood()`이 매번 `localStorage`를 새로
   읽는 구조라, 직전에 메모리에 남아있던 값과 무관하게 스토리지가 비어있으면 진짜 "정상값
   없음" 상태로 처리된다.
3. 결과: `.current-card` 텍스트가 `기온: —`, `습도: —`(`💧 습도 —`)로 표시됐고,
   "정상값 마지막 확인 (KST)"도 `—`, "마지막 조회 시각"도 `정상값 없음 — 다시 시도해
   주세요.`로 바뀌었다. **값을 지어내지 않는다는 기대값을 그대로 만족.**

## 4. 막힌 점

**없음.**

인계 문서와 harness.md만으로 프로젝트 목표, 개선 기능("습도 % 표시"), 검사 10개의 ID·
입력·기대값을 파악하는 데 어려움이 없었다. 다만 T05-C07을 재현할 때, 단순히
`localStorage.clear()` 후 `location.reload()`만 하면 페이지가 즉시 실제 API를 다시 호출해
정상값을 채워버려서 "정상값이 아예 없는 최초 상태"가 사라지는 함정이 있었다 — 이는 문서의
지시(`localStorage.clear()` 실행 후 오프라인 버튼 클릭)를 리로드 없이 순서 그대로 따르자
바로 해결됐다. 즉 문서의 재현 방법 자체는 정확했고, 실행 시 "리로드하지 말 것"이라는 세부
사항이 문서에 명시적으로 강조돼 있지는 않았던 점 정도가 유일한 사소한 함정이었다(문서를
불신하거나 이해가 안 돼서 막힌 것은 아님).
