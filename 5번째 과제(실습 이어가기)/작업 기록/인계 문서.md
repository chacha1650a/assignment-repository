## 7. 건드리면 안 되는 부분

- **`RECORDS_KEY`/`LASTGOOD_KEY` localStorage 스키마** — 습도는 의도적으로 날짜별 기록
  (`getRecords()`)과 어제 대비 비교(`renderCompare()`) 로직에 넣지 않았다 (harness.md 카드 1
  범위 축소 결정). 기록 객체에 `humidity` 필드를 추가하지 말 것 — 비교 로직이 `unit` 필드로
  단위를 비교하는데 습도 단위(%)가 섞이면 오작동할 수 있다.
- **`fetchRealWeather()`의 `format` 오류 판정 조건** (`typeof data.current.temperature_2m
  !== "number"`) — 기온 기준 그대로 두고, 습도는 별도로 안전 처리(`renderHumidity`)만 했다.
  습도 누락을 여기 조건에 추가하면 기온이 정상인데도 전체를 오류로 처리하게 되어 카드 3의
  "정상/오래된 데이터는 은은하게, 진짜 오류에만 전체 강조" 설계가 깨진다.
- **API 키/비밀값 추가 금지** — Open-Meteo는 공개 API. 습도 등 다른 파라미터를 더 추가하고
  싶어도 키가 필요한 출처로 바꾸지 말 것.
- **`#humidityFx`의 DOM 위치** — `#currentCard` 안, `#skyEmoji`보다 먼저 나와야 한다(뒤에
  깔려야 이모지·텍스트를 안 가림). `.current-card`의 `position:relative`도 그대로 둘 것 —
  지우면 연출이 카드 밖(전체 페이지)으로 새어나간다.
- **지도는 카카오맵/네이버맵/구글맵으로 바꾸지 말 것** — 전부 API 키·회원가입이 필요해서
  "비밀값 0건" 원칙과 충돌한다. CARTO 타일도 최근 정책 변경으로 키가 필요해져 기각함.
  Leaflet + **Esri World Street Map**(`server.arcgisonline.com`, CDN, 키 없음) 유지.
- **지도 초기화 시 `requestAnimationFrame(() => map.invalidateSize())` 지우지 말 것** —
  이게 없으면 컨테이너 크기 계산이 어긋나 줌이 이상해지는 버그가 실제로 있었다(1차 시도에서
  발견, 서울이 아니라 한중일 전역이 보이는 증상).
- **Leaflet UI(팝업/줌 버튼/저작권 표시) 커스텀 스타일에서 `!important` 빼지 말 것** —
  `leaflet.css`가 `style.css`보다 나중에 로드돼서 동일 우선순위 규칙은 Leaflet 기본값(흰
  배경 팝업 등)이 이긴다. 이미 한 번 이걸로 "지도 UI가 불친절하다"는 피드백을 받은 적 있음.
- **`.sky` 톤 색을 다시 밝게 되돌리지 말 것** — 사용자가 배경을 "진한 다크로 고정"으로
  결정했다(2026-08-28). 8개 tone 클래스 색만 어둡게 바꿨고 `applySky()` 로직은 그대로라
  회귀 검사 #10은 통과한다. 배경을 밝게 되돌리면 카드 배경(`rgba(38,50,72,.52)`)도 함께
  뒤집어야 한다 — 지금은 "어두운 배경 위에 밝은 카드" 구성이다.
- **차트 SVG를 숨길 때 `el.hidden = true` 쓰지 말 것** — SVG 요소에는 `hidden` IDL이 없어서
  속성으로 반영되지 않고, CSS `[hidden]` 선택자가 안 걸려 빈 차트가 355px를 차지한다.
  반드시 `setAttribute("hidden","")` / `removeAttribute("hidden")`를 쓸 것. (실제로 밟은 버그)
- **`hourly` 자료를 `format` 오류 판정에 넣지 말 것** — 습도와 같은 이유. 그래프 자료가
  없어도 기온 조회 자체는 성공으로 둬야 한다. 판정 조건은 `current.temperature_2m`만 본다.
- **차트 SVG의 `preserveAspectRatio`를 `none`으로 두지 말 것** — 눈금 숫자·시각 라벨이
  가로로 늘어난다. 기본값 + CSS `aspect-ratio:720/220` 조합을 유지할 것.
- **`.board-grid`/`.side-col` 구조 유지** — 기온 카드와 지도가 좌우로 나란히 앉는 레이아웃.
  `.side-col` 안, 지도 섹션 다음(주석 표시된 자리)에 **기온 그래프를 추가할 예정**이니 그
  구조를 깨지 말고 그 자리에 이어붙일 것.
