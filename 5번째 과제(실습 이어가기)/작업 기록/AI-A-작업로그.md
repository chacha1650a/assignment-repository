## 습도 연출 (2026-08-27, 사용자 요청으로 추가)

"습도 배지만으로는 개선이 밋밋해 보인다"는 피드백을 받아, **검사 10개·데이터 범위는 그대로
두고** 표현만 확장했다:

- 습도 30% 미만 → 카드 안에 먼지 입자 애니메이션 (amber 톤)
- 습도 70% 초과 → 카드 안에 빗방울 애니메이션 (blue 톤)
- 30~70%(오늘 서울 실제 값 65%처럼 흔한 구간)는 연출 없음 — 항상 켜져 있으면 임팩트가 없어서
  일부러 극단값에서만 반응하게 설계함.

**검증 방법**: 실제 서울 습도가 65%(연출 없음 구간)라 브라우저 콘솔에서
`document.getElementById('currentCard').classList.add('zone-humid'/'zone-dry')` 로 강제
적용해 시각 확인함(스크린샷 확인, 콘솔 에러 0건). **실제 API 응답이 30% 미만/70% 초과인
날에 실제 데이터로 재현 확인은 못 했다** — 코드상 `humidityZone()` 임계값 로직만으로
반응하므로 위험은 낮다고 판단하지만, AI B가 여유가 있으면 시간대를 바꿔서(예: 새벽/장마철)
한 번 더 실측 확인하면 좋다.
