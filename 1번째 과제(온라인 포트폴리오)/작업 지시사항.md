카드 1 — 대상과 공개 범위
하는 일
누구에게 보여줄 페이지인지 한 문장으로 정하고, 공개할 정보와 공개하지 않을 정보를 먼저 나눕니다.

첫 행동
빈 문서에 `이 페이지는 ______에게 ______를 보여주기 위한 것이다`를 채웁니다.
`공개할 것`과 `공개하지 않을 것`을 각각 3개씩 적습니다. 실명·학교·얼굴·연락처는 공개하지 않아도 되며 가명이나 포트폴리오용 이름을 써도 됩니다.
통과 기준
공개 주소가 바로 열리고 대상과 공개 범위가 화면에 보인다.
막히는 지점과 확인 순서
공개 경로를 정하기 어렵습니다.
정적 파일을 무료로 올릴 수 있는지 확인 → 가입만으로 사용할 수 있는지 확인 → 결제수단 등록이 필요 없는지 확인
주소가 열리지 않습니다.
첫 파일 이름이 index.html인지 확인 → 파일이 공개 폴더의 최상단에 있는지 확인 → 공개 설정과 새 주소를 다시 확인
남길 것
공개 주소 확인 — 공개 주소가 바로 열리고 대상과 공개 범위가 화면에 보인다.


카드 2 — 말이 아니라 근거
하는 일
강점이나 취향 3개를 다른 사람이 확인할 수 있는 상황·행동·결과로 바꿉니다.

첫 행동
각 항목을 `언제·어디서 있었는가 / 내가 실제로 무엇을 했는가 / 어떤 결과가 생겼는가` 세 칸으로 나눕니다.
최근 3개월 안에 끝까지 해본 일부터 적고, 숫자나 기관명은 억지로 만들지 않습니다.
통과 기준
소개 3개와 공개 가능한 근거 1개가 같은 화면에서 연결되어 보인다.
막히는 지점과 확인 순서
쓸 경험이 없다고 느껴집니다.
최근 3개월의 작은 완료를 하나 고름 → 그때 한 행동을 동사로 적음 → 행동 뒤 달라진 사실을 적음
근거 공개가 부담스럽습니다.
이름·기관·연락처를 제거 → 이미지를 가림 처리 → 공개가 어렵다면 관찰 가능한 결과 문장만 사용
남길 것
공개 주소 확인 — 소개 3개와 공개 가능한 근거 1개가 같은 화면에서 연결되어 보인다.


카드 3 — 첫 화면 재구성
하는 일
처음 3초 안에 나는 누구인지, 무엇을 하는지, 근거 한 가지가 보이도록 첫 화면을 고칩니다.

첫 행동
브라우저를 1366×768로 맞추고 스크롤하지 않은 상태에서 핵심 3개가 보이는지 확인합니다.
1920×1080으로 바꿔 과도한 빈 공간과 가로 스크롤이 생기는지 확인합니다.
통과 기준
첫 화면에 소개·활동·근거가 가로 넘침 없이 함께 보인다.
막히는 지점과 확인 순서
1366×768에서 핵심 내용이 잘립니다.
세로 여백을 먼저 줄임 → 이미지 크기를 줄임 → 제목과 본문 글자 크기를 마지막에 조정
1920×1080에서 내용이 지나치게 퍼집니다.
본문 최대 폭을 정함 → 본문을 가운데 정렬 → 핵심 묶음 사이 간격을 다시 확인
남길 것
공개 주소 확인 — 첫 화면에 소개·활동·근거가 가로 넘침 없이 함께 보인다.


카드 4 — 실제 결함 고치기
하는 일
눈으로 바로 보이지 않는 결함을 검사하고 실제 결함 3개 이상을 고칩니다.

첫 행동
모든 링크를 누르고, 마우스 없이 Tab 키로 처음부터 끝까지 이동하고, 개발자 도구 콘솔의 오류를 확인합니다.
제목 순서와 글자·배경 명암을 확인해 결함 목록에 수정 전 상태를 적습니다.
통과 기준
화면의 링크를 한 번 누르면 연결된 내용이 바로 표시된다.
막히는 지점과 확인 순서
결함을 찾기 어렵습니다.
Tab 이동 중 현재 위치가 보이는지 확인 → 링크 목적지가 맞는지 확인 → 제목 단계가 건너뛰지 않는지 확인
콘솔 오류 원인을 찾기 어렵습니다.
첫 오류 한 건만 선택 → 오류가 가리키는 파일과 줄을 확인 → 최소 수정 뒤 새로고침하여 같은 오류가 사라졌는지 확인
남길 것
공개 주소 확인 — 화면의 링크를 한 번 누르면 연결된 내용이 바로 표시된다.


카드 5 — 나와 연결된 재미
하는 일
페이지 내용과 관계있는 작은 상호작용 1개를 추가하고 키보드에서도 작동하게 만듭니다.

첫 행동
카드 2의 항목 하나를 고르고 자세한 이유를 펼치고 접는 것처럼 내용과 연결된 행동을 정합니다.
클릭 대상이 버튼인지 확인하고 Enter 또는 Space 키로도 실행되는지 검사합니다.
통과 기준
상호작용을 한 번 실행하면 화면이 즉시 바뀐다.
막히는 지점과 확인 순서
무엇을 만들지 정하기 어렵습니다.
강점 3개 중 하나를 고름 → 추가로 보여줄 문장 한 개를 정함 → 펼치기·접기처럼 한 동작으로 구현
키보드로 실행되지 않습니다.
클릭 대상이 button인지 확인 → Tab 키로 초점이 가는지 확인 → Enter와 Space 키를 각각 검사
남길 것
공개 주소 확인 — 상호작용을 한 번 실행하면 화면이 즉시 바뀐다.
