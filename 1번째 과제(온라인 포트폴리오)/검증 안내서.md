# 검증 안내서 — 온라인 포트폴리오

## 어디로 가나요
https://chacha1650a.github.io/assignment-repository/

## 무엇을 하나요 (3단계 이내)
1. 위 주소 접속 → "01 온라인 포트폴리오" 카드 클릭
2. 첫 화면에서 이름·소개·기술 스택·GitHub 버튼이 스크롤 없이 보이는지 확인
3. 아래로 스크롤해 강점 카드 3개 중 아무 곳이나 "자세히 보기" 버튼 클릭 (Tab으로 이동 후 Enter/Space도 가능)

## 무엇이 보이면 통과인가요
- 1번 클릭 후 1초 안에 포트폴리오 페이지가 열린다
- 3번 클릭(또는 Enter/Space) 즉시 카드가 부드럽게 펼쳐지며 상황·행동·결과 내용이 나타나고, 테두리에 색이 들어온다

## 안 될 때
- 페이지가 안 열림 → 새로고침 1회 (일시적 배포 지연일 수 있음)
- 카드가 안 펼쳐짐 → 페이지 새로고침 후 다른 카드로 재시도, 또는 다른 브라우저로 접속
