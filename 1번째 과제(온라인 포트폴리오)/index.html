강점과 근거

4인 팀 프로젝트 Clov.(친구와의 약속과 추억을 기록하는 웹 서비스, 2026.06.26 ~ 2026.08.14)에서 상점(Shop) API를 담당하며 실제로 확인한 강점입니다. 자세한 코드는 GitHub 저장소에서 확인할 수 있습니다.

  • 정보를 한곳에 모아 정리하는 힘

    API 명세와 데이터 구조를 문서로 먼저 정리해 팀이 함께 참고할 기준을 만들었습니다.

    상황
    Clov 프로젝트는 코드를 먼저 작성하지 않고 API 계약과 DB 설계를 먼저 정리하는 방식(Contract-First)으로 진행되었습니다.
    행동
    담당한 상점(Shop) 도메인의 API 명세와 데이터 구조를 문서 저장소에 정리해 팀원들과 공유했습니다.
    결과
    팀원들이 각자 맡은 도메인을 같은 기준 위에서 병렬로 개발할 수 있었습니다.

  • 끝까지 포기하지 않는 근성

    동시 요청 시 잔액이 꼬이는 문제를 원인부터 끝까지 파고들어 해결했습니다.

    상황
    상점 아이템을 골드로 구매할 때, 여러 요청이 동시에 들어오면 잔액이 잘못 차감될 수 있는 동시성 문제가 있었습니다.
    행동
    원인을 끝까지 분석해 지갑에 행 단위 잠금(row-level lock)을 적용하고 구매 로직을 다시 설계했습니다.
    결과
    동시에 여러 구매 요청이 들어와도 잔액 오류 없이 처리되고, 거래 내역이 기록되어 추적할 수 있게 되었습니다.

  • 맡은 바를 성실히 수행하는 책임감

    상점 도메인 전체를 단독으로 맡아 기간 내 완성하고 배포까지 마쳤습니다.

    상황
    4인 팀 프로젝트에서 상점(Shop) 도메인 전체를 혼자 담당하게 되었습니다.
    행동
    아이템 조회, 구매, 거래 내역 조회 API를 정해진 기간 안에 설계하고 구현했습니다.
    결과
    2026년 8월 14일 마감 기한 내 기능을 완성하고 배포까지 마쳤습니다.
