# 콘솔 오류 0건 확인

## 확인 방법
헤드리스 브라우저(Edge)로 실제 공개 주소를 로드하며 콘솔 로그를 기록:
```
msedge --headless --enable-logging=stderr --v=1 --dump-dom \
  "https://chacha1650a.github.io/assignment-repository/1번째 과제(온라인 포트폴리오)/index.html"
```

## 결과
페이지 자체(`index.html`, `style.css`, `script.js`)에서 발생한 **JavaScript 오류(빨간 오류) 0건**.

로그에 남은 항목은 모두 페이지와 무관한 브라우저 자체 메시지입니다:
- `CONSOLE` 로그 1건 — 브라우저 확장 프로그램(`chrome-extension://...background.rollup.js`)에서 발생, 우리 페이지 코드 아님
- `ERROR` 1건 — Chromium 내부 task manager 관련 메시지(`fallback_task_provider.cc`), 페이지 로드와 무관한 브라우저 자체 이슈

원본 로그: `console_log_raw.txt` (같은 폴더)

## 추가 확인 (개발자 도구 기준)
같은 페이지를 실제 브라우저 개발자 도구(F12) → Console 탭에서도 별도로 확인했으며, 페이지 로드/링크 클릭/강점 카드 펼치기·접기 상호작용 중 오류 0건이었습니다.
