## 상호작용 검증 방법
- **마우스**: 버튼 클릭 → 위 before/after 스크린샷처럼 펼침 애니메이션 발생
- **키보드**: 강점 카드 버튼은 네이티브 `<button>` 요소로, Tab으로 포커스 이동 후 Enter/Space로 동일하게 작동 (표준 HTML 동작이며, Tab 포커스 이동 순서는 별도로 확인함)
- **모션 감량**: `prefers-reduced-motion: reduce` 설정 시 애니메이션 없이 즉시 전환되도록 처리됨
